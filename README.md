# Wordle

A simple Wordle game featuring a WPF-based user interface, built with C# and .NET.

## Features
- Interactive graphical user interface using WPF.
- Guess the hidden word in a Wordle-style game.

## Requirements
- Windows
- The appropriate .NET runtime or SDK for the project.

## Getting Started
1. Clone or download the repository.
2. Open the solution in Visual Studio.
3. Build and run the project.

## Important: Smart App Control

Smart App Control must be turned off to run the application if Windows blocks it.

To change this setting, open Windows Security → App & browser control → Smart App Control settings and turn Smart App Control off.

Note: Turning Smart App Control off is a security trade-off. Windows does not provide a simple way to turn it back on; re-enabling it may require resetting or reinstalling Windows. Only run applications you trust.
